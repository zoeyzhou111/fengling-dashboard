# 战队长 · 手机端风灵在线怎么做（可直接转发）

电脑端在线不算完成。口头「登了」不算。**次日名单里没这个人，才算完成。**

---

## 每天 3 步（13:00 开会）

**第1步 13:00–13:20**  
打开《初短手机端不在线名单》本部门页，只看本队。先问：现在工作机登上了没有？  
→ 已登录：最前一列「是否已登录」选 **是**，问题分类选 **已登录**。不用报 POC。

**第2步 13:20–13:40**  
剩下的人对照下面五类，每人只选一个。缺字段 = 没报，14:00 POC 不处理。

**第3步 13:40–13:50**  
交表。个人原因你自己盯切机。不要让伙伴去找王慧或周萌。

班次：13:00–22:00（周二从 18:00 开始）。13:00 前不要催登录。

---

## 五类怎么标、谁去办

| 问题分类 | 什么情况 | 你怎么填 | 谁去办 |
|---|---|---|---|
| 已登录 | 开会时已经登上 | 是否已登录=是 | 不用报 POC |
| 设备问题 | 手机卡顿 / 无法使用 / **没有工作机** | 分类+现象写清 | POC 转五楼行政 **王慧** |
| 封号 | 企微被封 / 提示有风险 | 分类 + **截图已交=是** | 截图给 POC **周萌** |
| 风灵问题 | 环境异常 / 频繁退登 / 要同一环境 | 分类 + **UDID**（企微插件 App 里复制） | UDID 给 POC **周萌** |
| 个人原因 | 私人手机号 / 不想登工作机 | 分类+现象 | **你自己**限期切机，POC 不管 |

## 怎样最高效把率做上去（按这个顺序）

1. **先清已登录** — 10 分钟拿掉一批，不用走 POC。  
2. **当场收齐截图和 UDID** — 缺一张图、缺一个号，整单退回，白开会。  
3. **没工作机的整队写成「没有工作机」** — 行政一次发，比你逐个催快；领机当天必须登。  
4. **私人登录你自己死盯** — POC 劝不了，拖一天名单还在。  
5. **次日只追「昨天该好、今天还在」的人** — 不要每天把全队名单重念一遍。
