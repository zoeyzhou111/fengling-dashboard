# 答疑减负 · 可复制话术（不砍回复、不发新规）

用法：手机快捷回复里各存一条。私聊用「短句」；完整步骤只发在公司已有答疑群。领导口径变了，改文档、不改态度。

---

## 一、私聊短句（先回人，再把长答案放到群）

### 通用（90% 私聊用这个）

收到，我在【xx答疑群】按标准步骤回了。你按群里的做；做完还不行，把截图回群里（不要只发文字）。

@战队长先盯一眼，缺截图/UDID 的我这边接不了。

### 对方追问「你直接告诉我」

步骤我写在群里了，私聊容易口径不一致。你打开群里刚才那条，三步做完把结果截图回群，我看着办。

### 对方连发很多条 / 语音很长

先看群里那条。你只要回我 4 样：学部+战队、账号、电脑还是手机、现在屏幕截图。缺一样我没法判断。

### 13:00 前催登录（初短班次）

咱们班次 13:00 才上班（周二 18:00）。现在催登录看板对不上。13:00 后让战队长按不在线名单勾「是否已登录」。

### 口头说「我登了」

口头不算。次日名单里没有这个人，才算完成。先让战队长在表上标「已登录」，明天数据核销。

### 重复问题、你已经回过

还是上次那三步，群里那条还在。按完把新截图发群，我只看新图，不重新讲一遍。

### 非你闭环、但人已经找到你了（不说「不归我」）

这题我帮你看到下一步：按群里步骤做完。还不行让战队长填分类后升级，我盯结果。你先去做前三步。

## 二、群内长答模板（完整答案只出现在这里）

复制时替换【】。末尾都 @战队长，不要只 @伙伴。

### 模板 A · 手机端风灵没在线 / 不知道怎么登工作机

【姓名】手机端在线，按这个做（电脑端在线不算完成）：

1. 用工作机打开企微/风灵，不要用私人手机号硬登。
2. 登上后让战队长在《不在线名单》本队「是否已登录」选「是」，问题分类选「已登录」。
3. 次日名单还在，再改分类，不要反复私聊说「我登了」。

@战队长 13:20 前把未登录的人标成五类之一，缺字段当没报。

还不行再升级时必须带：账号 + 手机屏幕截图。个人原因（私人号/不愿切机）战队长自己盯，不要转我。

### 模板 B · 封号 / 提示有风险

封号只处理「有截图」的：

1. 截图：企微被封或风险提示全屏（含账号）。
2. 战队长在表上：问题分类=封号，截图已交=是。
3. 截图发我（POC），不要只发「被封了」。

缺截图会退回。@战队长 开会当场收齐，不要让伙伴单独找行政。

### 模板 C · 风灵环境异常 / 频繁退登

风灵问题必须带 UDID，没有 UDID 我处理不了：

1. 打开企微插件 App，复制 UDID。
2. 战队长填：问题分类=风灵问题 + UDID。
3. 把 UDID + 异常截图发群。

@战队长 缺 UDID 的先退回，不要攒一堆「环境不行」的空单。

### 模板 D · 授权 / 爱芯后台

先对这三样，再判断：

1. 用的哪个账号（和接流账号是否同一人）。
2. 爱芯后台授权页截图（授权成功/失败原文）。
3. 学部+战队。

先发这三样到本群。不要先问「你帮我看一下授权怎么了」——没有截图只能猜。
@战队长 本队今天授权未过的人，收齐截图后一次性发，不要一个人私聊一次。

### 模板 E · 电脑端可以、手机端不行

电脑端 85%+ 很常见，问题几乎都是手机端没登工作机。

请战队长当场问：现在工作机登上了没有？
- 登上了 → 表上标已登录，等次日核销。
- 没工作机 → 分类「设备问题」+ 写清「没有工作机」，我转行政王慧，不要让伙伴私聊王慧。
- 有机但不想用工作号 → 个人原因，战队长限期切机。

@战队长 按这个分，不要把三种情况都丢成「手机登不上」。

## 三、政企机 / 工作机（帮到下一步，不现场修）

口径：你判断「能不能自助」；发机/坏机走行政王慧；伙伴不要直接找王慧。

### 私聊短句

设备我帮你看到自检三步（群里发了）。三步还不行，让战队长写成「设备问题」+现象，我 21:40 前打包转王慧，你把战队名回我，我帮盯发放/维修结果。

### 群内：自检三步（先做完再升级）

政企机/工作机先做这三步，做完把每一张截图回群：

1. 能开机、能亮屏；插卡/Wi‑Fi 能上网（打开任意网页）。
2. 用工作号打开企微，能进首页（不要私人号）。
3. 打开风灵/插件，能停在工作界面，不闪退。

三步都过但仍不在线 → 按风灵问题交 UDID。
第 1 步就失败（卡顿/无法使用/没机）→ 战队长填「设备问题」+现象（没机就写「没有工作机」），我转王慧，领机当天必须登。
不要让伙伴直接找王慧或我私人修机。

@战队长 没工作机的整队写成同一句话「没有工作机」，行政一次发比逐个催快。

### 升级给王慧时你自己用的打包话术（内部）

王慧，今日设备打包（截止 21:40）：
- 部门/战队：
- 姓名：
- 现象：卡顿 / 无法使用 / 没有工作机（三选一）
- 自检三步是否已做：是/否
- 期望：发机 / 换机
领机当天请战队长盯登录。谢谢。

### 伙伴说「你帮我找王慧」

可以，但要走表：让战队长填设备问题+现象。我晚上打包给王慧。你现在先做自检三步，把截图回群，避免行政收到空单。

这样在线率、授权、设备可用我还能盯住。重复问题我按您上次的口径写成标准答法，您在群里拍过的板，我按您的执行。
